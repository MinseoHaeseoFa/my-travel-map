# 🧭 나의 여행 지도 (My Travel Map)

> **쿠사리님의 발길이 닿은 모든 길을 기록하는 통합 여행 아카이브 허브**
> 국내 방방곡곡부터 전 세계 195개국, 100대 명산 트래킹까지 한곳에서 관리하는 모듈러(Hub & Spoke) 포털 대시보드입니다.

---

## 🏛️ 아키텍처 개요 (Hub & Spoke)

```
                       [ 🧭 나의 여행 지도 (my-travel-map) ]
                                    (통합 허브)
                                         |
     +-----------------------------------+-----------------------------------+
     |                                   |                                   |
[ 🇰🇷 대한민국 여행 지도 ]        [ 🌍 세계 여행 지도 ]        [ ⛰️ 100대 명산·트래킹 ]
 (korea-travel-map)               (world-travel-map)             (mountain-travel-map)
   - 167개 시·군 5단계 색칠          - 195개국 벡터 세계 지도        - 산림청/블랙야크 100대 명산
   - 1,670개 10대 명소              - 대륙/국가/수도 도시 기록       - 완등률 & 코스 난이도
   - 네이버 지도 연동                - 여권 스탬프 아카이브          - 둘레길/종주길 인증
   (LIVE 배포 완료)                  (2단계 구축 준비)               (3단계 구축 준비)
```

## ✨ 핵심 기능

1. **종합 통합 통계 대시보드**
   - 대한민국 167개 시·군 달성률 (%)
   - 전 세계 195개국 탐험률 (%)
   - 100대 명산 & 트래킹 완등률 (%)
2. **독립 모듈러 연동**
   - 방대한 지리 데이터가 섞이지 않는 가벼운 로딩 속도 유지
   - 독립된 서비스 간 원클릭 즉시 이동
3. **프리미엄 반응형 UI**
   - 다크 테마 글래스모피즘(Glassmorphism) 비주얼
   - 모바일 & PC 최적화 반응형 레이아웃
