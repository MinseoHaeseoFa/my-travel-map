# 🧭 나의 여행 지도 (My Travel Map)

> **쿠사리님의 발길이 닿은 모든 길을 기록하는 통합 여행 아카이브 허브**
> 국내 방방곡곡부터 전 세계 195개국, 100대 명산 트래킹까지 한곳에서 관리하는 모듈러(Hub & Spoke) 포털 대시보드입니다.

---

## 🏛️ 아키텍처 개요 (Hub & Spoke)

```
                       [ 🧭 나의 여행 지도 (my-travel-map) ]
                                    (통합 허브)
                                         |
     +-------------------+---------------+---------------+-------------------+
     |                   |               |                   |
[ 🇰🇷 대한민국 ]    [ 🌍 세계 여행 ]    [ ⛰️ 100대 명산 ]    [ 🧭 여행 플래너 ]
 (korea-travel-map)  (world-travel-map)  (mountain-travel-map)  (my-travel-planner)
   - 167개 시·군       - 195개국 지도       - 100대 명산          - 7탭 일정·티켓
   - 1,670개 명소      - 도시·명소 기록     - 완등률·코스         - 준비물·예산·맛집
   - 네이버 지도       - 여권 스탬프        - 둘레길·종주길       - 오프라인 지갑
```

> 3대 Trail Log는 지난 발자취를 기록하고, 4번째 **여행 플래너**는 다가올 여행을 준비합니다.

## ✨ 핵심 기능

1. **종합 통합 통계 대시보드**
   - 대한민국 167개 시·군 달성률 (%)
   - 전 세계 195개국 탐험률 (%)
   - 100대 명산 & 트래킹 완등률 (%)
2. **독립 모듈러 연동**
   - 방대한 지리 데이터가 섞이지 않는 가벼운 로딩 속도 유지
   - 독립된 서비스 간 원클릭 즉시 이동
3. **프리미엄 반응형 UI**
   - 유화풍·크림 뉴모피즘 비주얼 (좌측 로고 레일 · 위치 기반 실시간 날씨)
   - 모바일 & PC 최적화 반응형 레이아웃
4. **여행 플래너 연결**
   - `https://my-travel-planner-kohl.vercel.app/` — 일정·티켓·준비물·예산·맛집 7탭 오프라인 여행 지갑
   - 허브 카드 4번째 및 좌측 로고 레일에서 바로 이동 (기존 3대 앱과 동일하게 현재 탭 이동)
